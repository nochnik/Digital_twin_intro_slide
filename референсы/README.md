# Референсы

Скриншоты и снимки, по которым переделывались слои. Лежат в репозитории,
потому что работа идёт с двух машин, а без исходного референса слой не
воспроизвести.

## Составляющие пласта

| Файл | Что на нём | Куда пошёл |
|---|---|---|
| `слой 1.png` | куб гидродинамической модели в изометрии, шкала «синий → зелёный → жёлтый → красный», ступенчатые края ячеистой сетки | `пласт_1_ггдм.glb` |
| `2_sloi.png` | карта по площади в той же шкале, вид сверху | `пласт_2_стратегия.glb` |
| `3_sloi.png` | сетка с точками бурения и ранжированием | верхняя составляющая (ТЭО) — собирается кодом, модели нет |
| `реф_карта_остаточных_запасов.png` | карта остаточных запасов | опорный по цвету и характеру заливки |

`_ген_слой1.png`, `_ген_слой2.png` — что выдал генератор по этим референсам,
оставлены для сверки: по ним видно, насколько результат отошёл от исходника.
