# Цифровой двойник на базе ИС ABAI — первый слайд показа

Интерактивная 3D-модель актива для вводного блока демонстрации.
Пилот — месторождение Молдабек Восточный (АО «Эмбамунайгаз»).

**Онлайн:** https://nochnik.github.io/Digital_twin_intro_slide/

## Как это работает

Куб месторождения собран из отдельных 3D-моделей слоёв. Наведение на слой
переводит его в цифровую копию — каркас, сетка, частицы данных. Клик выносит
слой в центр, остальные раздвигаются; справа открывается панель контура
с эффектами и модулями.

| Контур | Что показывает |
|---|---|
| 01 · ЦД пласта | Три составляющие: ГГДМ · стратегия разработки · проектирование и ВНС. Каждая — отдельная модель, свой цвет, своя модалка |
| 02 · ЦД скважины | Стволы под качалками, при выборе подсвечиваются фиолетовым |
| 03 · ЦД добычи и наземной инфраструктуры | Фонд, УПН, резервуарный парк, факел, трубопроводы, подстанция |

ЦД ресурсной базы (ГРР) скрыт до уточнения периметра — контур 2027 года.

## Запуск локально

Нужен статический сервер: модели `.glb` браузер не читает с `file://`.

```
start.bat
```

Двойной клик — поднимет сервер и откроет браузер. Работает на Node.js,
при его отсутствии пробует Python.

## Автономная версия

Для показа без сервера собирается один файл со всем содержимым внутри:

```
node build_standalone.js
```

Результат — `ПОКАЗ_автономный.html` (~37 МБ), открывается двойным кликом,
интернет не нужен. Пересобирать после каждой правки `первый_слайд_v3.html`.
